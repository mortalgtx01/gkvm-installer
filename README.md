# GKVM Panel V1

## Installation

Run:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mortaltgx01/gkvm-installer/main/install.sh)
```

The installer will automatically:

- Install dependencies
- Download GKVM Panel
- Configure systemd
- Start the panel

After installation:

http://YOUR_SERVER_IP

Login using your admin account.

License activation is required on first login.
